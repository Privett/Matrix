Что делает Matrix

Matrix находит раздачи игр и DLC и отправляет уведомления в выбранный канал. Доп. настройки под сервер возможны по запросу.

🎯

Поиск раздач

Проверяет источники раздач: Epic Games и Steam, GOG — частично. Берёт только реально бесплатное.

📢

Уведомления в канал

Уведомления идут в один выбранный канал на сервере. Формат — Discord embed.

⚙️

Команды под сервер

Если надо — можно адаптировать команды/поведение под конкретный сервер. Панели настроек нет.

Под каждый сервер — свои правила

По запросу можно адаптировать команды или поведение Matrix под конкретный сервер.

⚙️

Как это работает

  • Команды/поведение — по запросу. Если нужно, я могу подстроить Matrix под конкретный сервер.
  • Один канал для уведомлений. Все раздачи игр и DLC отправляются в один выбранный канал.
  • Фильтры — внутри бота. Пользовательских фильтров сейчас нет.
  • Локализация — позже. Сейчас один формат дат/времени, позже добавлю локализацию.
Шаг 1

Пригласи Matrix

Добавь бота по ссылке выше и выдай ему права на чтение и отправку сообщений в нужных каналах.

Шаг 2

Выбери канал для уведомлений

Открой тот текстовый канал на сервере, куда хочешь получать раздачи, и напиши в нём команду /addchannel role:@game_giveaway giveaway_delete:Yes Matrix привяжет этот канал и будет отправлять все уведомления туда.

Ответы на частые вопросы

Если чего-то не хватает или нужна другая логика — можно обсудить и добавить по запросу.

Matrix бесплатный?
Да, сейчас Matrix бесплатный. Поддержка (Patreon/крипта) — добровольная.
Нужны ли права администратора?
Нет. Достаточно прав на чтение/отправку сообщений в выбранном канале.
Какие площадки поддерживаются?
Epic Games и Steam. GOG — частично.
Можно ли сделать настройки только для одного сервера?
Да. Если нужно особое поведение/команды — можно договориться и сделать под ваш сервер.
